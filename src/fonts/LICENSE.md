# Shriftlar litsenziyasi

Bu papkadagi shriftlar [SIL Open Font License 1.1](https://openfontlicense.org) ostida tarqatiladi. Ularni saytda ishlatish, loyiha bilan birga saqlash va tarqatish mumkin. Shriftlarni alohida sotish mumkin emas.

| Fayl                   | Shrift                                                         | Mualliflar                  |
| ---------------------- | -------------------------------------------------------------- | --------------------------- |
| `geologica-*.woff2`    | [Geologica](https://fonts.google.com/specimen/Geologica)       | Monokrom Type Foundry       |
| `onest-*.woff2`        | [Onest](https://fonts.google.com/specimen/Onest)               | Dmitri Voloshin, CSTM Fonts |
| `martian-mono-*.woff2` | [Martian Mono](https://fonts.google.com/specimen/Martian+Mono) | Evil Martians               |

Fayllar Google Fonts'dan olingan (lotin va kirill qismlari, o'zgaruvchan shriftlar). Yangilash kerak bo'lsa, xuddi shu qismlarni `fonts.googleapis.com/css2` orqali qayta yuklab oling.
