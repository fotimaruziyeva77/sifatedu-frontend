# Shriftlar litsenziyasi

Bu papkadagi shriftlar [SIL Open Font License 1.1](https://openfontlicense.org) ostida tarqatiladi. Ularni saytda ishlatish, loyiha bilan birga saqlash va tarqatish mumkin. Shriftlarni alohida sotish mumkin emas.

| Fayl                     | Shrift                                                             | Mualliflar                  |
| ------------------------ | ------------------------------------------------------------------ | --------------------------- |
| `geologica-*.woff2`      | [Geologica](https://fonts.google.com/specimen/Geologica)           | Monokrom Type Foundry       |
| `onest-*.woff2`          | [Onest](https://fonts.google.com/specimen/Onest)                   | Dmitri Voloshin, CSTM Fonts |
| `martian-mono-*.woff2`   | [Martian Mono](https://fonts.google.com/specimen/Martian+Mono)     | Evil Martians               |
| `rubik-*.woff2`          | [Rubik](https://fonts.google.com/specimen/Rubik)                   | The Rubik Project Authors   |
| `inter-*.woff2`          | [Inter](https://fonts.google.com/specimen/Inter)                   | The Inter Project Authors   |
| `jetbrains-mono-*.woff2` | [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) | The JetBrains Mono Authors  |

Geologica, Onest va Martian Mono Google Fonts'dan olingan (lotin va kirill qismlari, o'zgaruvchan shriftlar). Yangilash kerak bo'lsa, xuddi shu qismlarni `fonts.googleapis.com/css2` orqali qayta yuklab oling.

Rubik, Inter va JetBrains Mono — dars slaydlari uchun (`slides.ts`), [Fontsource](https://fontsource.org) paketlaridan (`@fontsource-variable/*` 5.3.0, fayllar `*-latin-wght-normal.woff2` va `*-cyrillic-wght-normal.woff2`).
